🚀 التحسينات العامة والأداء:

تحسينات كبيرة في السرعة وسلاسة التنقل داخل جميع أقسام البلوجن.

سرعة فائقة في فتح سيرفرات MAC وتحميل الصفحات بالكامل.

تحسين واجهة المستخدم وتوحيد الألوان في جميع الشاشات.

إضافة صفحة ويب (Web Interface) لإدارة السيرفرات والتحكم بها، ومعرفة حالة السيرفر والـ Ping (عبر الرابط: http://ip:7090).

تطوير شكل عرض شاشة الضبط لتصبح مقسمة وأسهل في الاستخدام، مع إمكانية التنقل بين الأقسام بأزرار < >.

إضافة زر 5 داخل الأقسام لعرض شاشة مساعدة تشرح وظيفة كل زر.

إصلاح وتطوير نظام تنظيف أسماء الأفلام والمسلسلات التي تأتي من السيرفرات بشكل مختلف أو غير مرتب.

تحسينات عامة وإصلاح عدد كبير من الأخطاء السابقة.

📺 قسم البث المباشر (Live TV):

إصلاح وتحسين التسجيل المباشر من القنوات عبر زر INFO (تم حل مشكلة توقف التسجيل بعد وقت قصير).

إخفاء القنوات والأقسام عبر زر 2، وإظهارها مجدداً عبر زر 3.

قائمة جانبية سريعة للتنقل بين الأقسام بضغطة زر 1.

تصدير باقات القنوات (Categories) إلى المفضلة (Bouquets) عبر زر 4.

تصدير روابط القنوات إلى إضافة الصوتيات (IPAudio) عبر زر 5.

دعم خاصية المشاهدة الفائتة (Replay / Catch-up) في السيرفرات الداعمة عبر زر EPG.

دعم كامل لـ XtreamEPGGrabber مع إمكانية ربط (Assign) معلومات كل قناة.

ثلاثة خيارات مرنة لعرض دليل البرامج (EPG) بالضغط على زر MENU ثم الأزرق:

IPTV Server / Local: لعرض EPG السيرفر فقط.

Assigned XML: لعرض قنوات الـ EPGGrabber المربوطة فقط.

Hybrid: دمج الاثنين معاً (يعطي الأولوية للمربوط، ثم يكمل النواقص من السيرفر) لضمان تغطية كل القنوات.

🎬 قسم الأفلام والمسلسلات (VOD & Series):

شاشات العرض: توفير عدة أشكال للعرض (Grid و Carousel).

تم تغيير وتحديث شكل الـ Carousel في القائمة الرئيسية، مع تسريع التنقل فيه بشكل كبير.

عند اختيار شكل Cinematic: أصبح بإمكانك تفعيل أو إيقاف خلفيات (Backdrop).

إضافة موسيقى تصويرية للمسلسلات (Series Theme) تعمل تلقائياً عند الدخول للمسلسل (يمكن إيقافها أو التحكم بها من الضبط).

إضافة علامة WATCHING لمعرفة المسلسلات التي تتابعها، وتتحول تلقائياً إلى COMPLETE عند الوصول لآخر حلقة.

قائمة جانبية سريعة (Category Menu) تفتح بزر 1 داخل الأقسام لسهولة اختيار التصنيف وعرض عدد محتوياته.

شريط تنقل علوي سريع (Top Navigation).

التنقل بين الصفحات عبر أزرار CH+ / CH-.

بحث سريع داخل الأقسام بزر الأزرق، ومسح البحث بزر 3.

ترتيب محتوى الصفحة (Sort) بزر الأخضر.

تشغيل الإعلان الترويجي (Trailer) بضغطة واحدة عبر زر 2.

عرض معلومات IMDb عبر زر INFO.

إضافة مدة العرض (Runtime) داخل صفحات الأفلام، المسلسلات، والحلقات.

إصلاح عرض معلومات النوع (Genre) لتصبح منسقة وملتصقة بشكل صحيح حتى عند ترجمتها للعربية.

إدارة التحميلات (Download Manager): ضغطة بزر 0 تمكنك من تحميل فيلم، موسم كامل، أو حلقة منفردة، مع ظهور علامة تحميل على البوستر. (زر MENU يفتح قائمة التحميلات للتحكم بها).

المفضلة: زر الأصفر للإضافة (يظهر علامة نجمة على البوستر)، وزر الأحمر للإزالة. زر 4 لتصدير قسم كامل للمفضلة.

إشعار ذكي للتشغيل التلقائي للحلقة التالية يظهر قبل انتهاء الحلقة بدقيقة.

🔤 مشغل الفيديو والترجمة (Player & Subtitles):

شريط تحكم علوي (Top Bar) يفتح بالزر الأخضر للتحكم في (تغيير خط الترجمة، البحث، تأخير/تقديم الترجمة، ومسار حفظ الترجمة).

حفظ إعدادات الترجمة واستعادتها تلقائياً عند الرجوع لاستكمال الفيلم لاحقاً.

إصلاح مشكلة ظهور الترجمات المدمجة (Embedded Subtitles).

إضافة موقع SUBDL للبحث عن الترجمات (يتطلب إدخال المفتاح من الضبط).

إضافة اللغة الفرنسية لمحرك ترجمة Subsource و TMDB.

دعم كيبورد NewVirtualKeyboard أثناء البحث عن الترجمات (يمكن اختياره من الضبط).

⚙️ شاشة الإعدادات والصيانة (Settings & Maintenance):

إضافة "مركز الصيانة - Maintenance Center" للتحكم الشامل: (تنظيف الكاش، حذف الملفات المؤقتة، وحذف صور الـ Artwork والكاش).

خيارات جديدة ومخصصة لترجمة معلومات TMDB (النوع Genre، البلد Country، ومدة العرض Runtime) باستخدام قاموس خاص بالبلوجن لضمان ترجمة دقيقة تتفادى أخطاء TMDB، مع توفير خيارات متعددة.

تحديد مكان حفظ ملف إعدادات البلوجن (Settings) عبر زر MENU من شاشة الضبط.

إمكانية إدخال مفاتيح API الخاصة بـ (TMDB, OMDB, SUBSOURCE, SUBDL) مباشرة من الضبط.

التحكم في ألوان البلوجن، وتحديد عدد كلمات القصة (Plot).

📌 ملاحظات هامة:

يُفضل جداً استخدام (HDD أو USB) لحفظ الكاش من أجل أداء أسرع وأكثر استقراراً.

يحتوي البلوجن على نظام فلترة مدمج لإخفاء المحتوى غير المناسب.

دعم التحديث الهوائي (OTA) مباشرة من داخل البلوجن لأي إصدارات قادمة.

هام للمستخدمين الحاليين: يُرجى مسح فولدر الكاش القديم من الهارد ديسك لضمان عمل التحديثات الجديدة بكفاءة


🚀 General & Performance Improvements:

Massive improvements in speed and UI navigation fluidity across all plugin sections.

Lightning-fast MAC server connection and page loading speeds.

UI enhancements with unified colors across all screens.

Added a Web Interface to manage servers, check ping, and monitor server status (Access via: http://ip:7090).

Redesigned the Settings menu to be tab-categorized and easier to navigate using the < > buttons.

Added an on-screen Help guide inside sections by pressing button 5 to explain all remote key functions.

Improved and fixed the title cleaning algorithm for movies and series fetched from different servers.

General system optimizations and numerous bug fixes.

📺 Live TV Section:

Fixed and improved Direct Recording via the INFO button (resolved the issue where recording stopped prematurely).

Hide channels and categories using button 2, and unhide them using button 3.

Quick sidebar menu to navigate between categories using button 1.

Export entire categories to Bouquets/Favorites using button 4.

Export channel links directly to the IPAudio plugin using button 5.

Full Replay / Catch-up support (if provided by the server) via the EPG button.

Full support for XtreamEPGGrabber with the ability to assign info to channels.

Three flexible EPG display modes (Access via MENU -> Blue button):

IPTV Server / Local: Display only the server's native EPG.

Assigned XML: Display only EPG for channels assigned via EPGGrabber.

Hybrid: (Assign first + Server fallback) ensures maximum EPG coverage for all channels.

🎬 Movies & Series (VOD) Section:

Views: Multiple layout options including Grid and Carousel.

Redesigned the Carousel layout in the main menu and significantly improved its scrolling speed.

Cinematic View: Added the ability to enable/disable Backdrop images.

Added Series Theme Music: Soundtracks play automatically upon entering a series (Toggleable from settings).

Added Watch Status Tracking: Displays a WATCHING tag, which automatically switches to COMPLETE on the final episode.

Added a quick Category Menu inside sections (Press button 1) to easily select categories and view item counts.

Fast Top Navigation bar.

Page navigation using CH+ / CH- buttons.

Quick search within sections using the Blue button, and clear search with button 3.

Sort page content using the Green button.

Play the Trailer instantly by pressing button 2 on a movie/series.

Show IMDb information using the INFO button.

Added Runtime information to movies, series, and episode pages.

Fixed Genre layout and spacing to be compact and properly aligned, even when translated to Arabic.

Download Manager: Press button 0 to download a movie, a full season, or a single episode. A download icon will appear on the poster. (Press MENU to open and manage your downloads).

Favorites: Add items using the Yellow button (displays a star icon), and remove them with the Red button. Export an entire category to favorites with button 4.

Smart Auto-play notification for the next episode appears 1 minute before the current episode ends.

🔤 Player & Subtitles:

Top Bar Menu (Press Green button) to control: Subtitle Font, Subtitle Search, Subtitle Delay/Sync, and Save Path.

Subtitle states and settings are automatically saved and restored when resuming a movie.

Fixed the display issue with Embedded Subtitles.

Added SUBDL as a new subtitle provider (requires entering the API key in Settings).

Added French language support to Subsource and TMDB.

Support for NewVirtualKeyboard during subtitle searches (selectable from Settings).

⚙️ Settings & Maintenance:

Added a new "Maintenance Center" for full plugin management: (Clear Cache, Delete Temp Files, and Delete Artwork/Images Cache).

Advanced dictionary-based translation options for TMDB data (Genre, Country, Runtime) to bypass native TMDB translation errors, featuring multiple configuration choices.

Ability to choose the save location for the Settings file via the MENU button inside Settings.

Dedicated inputs for API keys (TMDB, OMDB, SUBSOURCE, SUBDL) directly within the Settings screen.

Customize plugin theme colors and set the maximum word count for the Plot description.

📌 Important Notes:

It is highly recommended to use an external HDD or USB drive for caching to ensure the best performance.

The plugin includes a built-in filter to hide inappropriate content.

In-app Over-The-Air (OTA) updates are supported for all future releases.

Important for existing users: Please delete the old Cache folder from your HDD/USB for this new update to function optimally.
